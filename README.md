# Nova Form — Scroll Experience

Eine cleane Apple-inspirierte Scroll-Webseite mit dunklem Premium-Look, sticky Scrollytelling und einem 3D-artigen Produkt-Visual.

## Inhalt

- `index.html` — Seitenstruktur
- `style.css` — Design, Visuals, Animationen
- `script.js` — Scroll-Logik und Kapitelwechsel

## Lokal starten

Einfach `index.html` im Browser öffnen.

Oder mit einem kleinen lokalen Server:

```bash
python -m http.server 8080
```

Dann öffnen:

```text
http://localhost:8080
```

## Idee

Das Projekt zeigt kein Uhr-Design, sondern ein fiktives Objekt namens **Nova Form**. Beim Scrollen verändern sich Kapitel, Farben, Produktposition, Licht und UI-Elemente.
